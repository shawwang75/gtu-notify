# GTU Notify - Odoo飞书业务通知推送

**GTU Notify** 是一款强大的Odoo模块，自动将业务事件通知推送到飞书，帮助团队实时跟踪关键业务事件。

## 🚀 核心功能

### 业务事件通知
- **CRM（客户关系管理）**：线索创建、分配、阶段变更、金额更新、关闭
- **项目管理**：项目创建、任务分配、状态变更、截止日期更新、完成
- **工时表**：创建、更新、删除

### 通知控制
- 三级通知开关（全局/模块/事件）
- 用户级通知偏好设置
- 富文本消息卡片，支持直接跳转到Odoo

### 技术优势
- ✅ 完全独立，零依赖
- ✅ 无需其他飞书模块
- ✅ 飞书应用配置管理
- ✅ 员工飞书账号绑定
- ✅ 自动Token刷新机制
- ✅ 失败安全设计，不影响业务操作
- ✅ 完全基于Odoo标准继承，零源码修改

## ⚙️ 配置指南

### 1. 创建飞书应用
1. 访问[飞书开放平台](https://open.feishu.cn/app)
2. 创建企业自建应用
3. 获取App ID和App Secret
4. 配置应用权限：
   - `contact:user.base:readonly` - 获取用户基本信息
   - `im:message` - 发送消息

### 2. 在Odoo中配置
1. 导航到 **设置 → GTU Notify → 飞书配置**
2. 输入App ID和App Secret
3. 点击"测试连接"验证配置

### 3. 绑定员工飞书账号
1. 进入 **员工** 模块
2. 编辑每个员工
3. 在"飞书账号"字段填入：
   - 飞书Open ID，或
   - 飞书手机号（自动匹配）

### 4. 启用通知
1. 导航到 **设置 → GTU Notify → 通知配置**
2. 启用需要的事件通知
3. 配置通知内容格式

## 📋 支持的事件

| 模块 | 事件 | 说明 |
|------|------|------|
| **CRM线索** | 创建、分配、阶段变更、金额更新、关闭 | 实时通知销售团队 |
| **项目任务** | 分配、状态变更、截止日期更新、完成 | 实时通知项目成员 |
| **工时表** | 创建、修改、删除 | 实时通知项目经理 |
